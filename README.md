# 出租车计价器 · Logisim 数字电路

用 **Logisim 2.7.1** 搭建的纯数字逻辑出租车计价器。全部功能由计数器、比较器、加法器、减法器、乘法器、数据选择器和触发器实现，不包含任何单片机或软件代码。

> 本仓库只包含 **Logisim 源文件** 与 **设计文档**，不包含课程设计报告。

## 计费规则

| 项目 | 规则 |
| --- | --- |
| 起步价 | 行程 ≤ 3 km：10 元 |
| 里程费 | 行程 > 3 km：`10 + 3 × (公里数 − 3)` 元 |
| 不足 1 km | 按 1 km 计（如 3.2 km 按 4 km 收费） |
| 等待费 | 每累计 1 分钟加 1 元，不足 1 分钟按 1 分钟计 |
| 距离脉冲 | 每个脉冲代表 50 m，20 个脉冲 = 1 km |
| 显示范围 | 4 位十进制（0000–9999），里程与金额分时显示 |

金额算例：

| 里程 | 金额 |
| --- | --- |
| 0–3 km | 10 元 |
| 4 km | 13 元 |
| 5 km | 16 元 |
| 10 km | 31 元 |
| 20 km | 61 元 |
| 3 km + 等待 2 分钟 | 12 元 |

## 快速开始

1. 安装 [Logisim 2.7.1](http://www.cburch.com/logisim/)（或兼容的 Logisim-evolution）。
2. 打开 `src/taxi-meter.circ`。
3. 确认菜单 `Simulation → Simulation Enabled` 已勾选，然后点击 `Simulation → Ticks Enabled`（或按 `Ctrl+T`）让时钟运行。
4. 按下面的操作流程演示。

> 建议使用 Logisim 2.7.1 打开；Logisim-evolution 也可以导入该版本的工程文件。

## 操作说明

| 控件 | 类型 | 作用 |
| --- | --- | --- |
| `启动` | 引脚（开关） | 模拟车钥匙：置 1 插入钥匙并启动，置 0 关闭 |
| `上下车切换` | 按钮 | 模拟乘客上车/下车，按一次切换一次 |
| `行等切换` | 按钮 | 在“行驶”和“等待”之间切换 |
| `模拟路程输入` | 按钮 | 每按一次代表车辆前进 50 m |
| `模拟等待输入` | 按钮 | 手动加入等待计时脉冲（等待时钟也会自动计时） |
| `reset` | 按钮 | 复位里程、金额与计时，开始新的行程 |
| 4 位数码管 | 输出 | 分时显示当前里程或金额 |
| 指示灯 | 输出 | 显示钥匙、载客、行驶状态，以及当前显示的是里程还是金额 |

推荐演示流程：

1. 点击 `reset` 复位。
2. 将 `启动` 置为 1（插入钥匙）。
3. 按一次 `上下车切换`：乘客上车，载客指示灯亮。
4. 按一次 `行等切换`：进入行驶状态，行驶指示灯亮。
5. 连续点击 `模拟路程输入` 累计里程：每 20 次为 1 km，观察 4 位数码管上的里程变化。
6. 需要模拟等待时，按 `行等切换` 切到等待状态；等待计时开始累计，每满 1 分钟金额加 1 元。也可用 `模拟等待输入` 手动打点，加快演示。
7. 到达后按一次 `上下车切换`，乘客下车，记录本次金额。
8. 按 `reset` 清除本次数据，开始下一位乘客的行程。

显示说明：4 位数码管会在“里程”和“金额”之间自动轮换，旁边的 `显示Km` / `显示Money` 指示灯会告诉你当前看到的是哪一个。金额固定显示 4 位，高位补 0（例如 `0010` 表示 10 元）。

## 电路组成

顶层 `main` 电路由五个功能区和若干子电路组成：

| 子电路 | 作用 |
| --- | --- |
| `毛刺` | 按键消抖 / 边沿脉冲产生，保证一次按键只触发一次 |
| `74Ls160` | 用 Logisim 计数器搭出的 74LS160 功能模型（异步清零、同步置数、使能、进位） |
| `99计数器` / `999` / `9999` | 2/3/4 位 BCD 级联计数器；顶层使用 `9999` 作为 4 位里程计数器 |
| `转2进制` | 4 位 BCD 里程 → 14 位二进制，供计费运算使用 |
| `公里计费器` | 由里程计算里程费：`10 + 3 × (km − 3)` |
| `切换显示` | 把 14 位金额/里程拆成 4 位 BCD，并选择当前显示源 |
| `分时显示` | 产生分时切换信号，让里程与金额轮流显示 |

更详细的原理、端口定义和验证过程见 [docs/DESIGN.md](docs/DESIGN.md)。

## 验证情况

`公里计费器` 子电路已在 Logisim 中逐点仿真（Km = 0…30）：

```text
Km   0  1  2  3  4  5  6 ... 10 ... 20 ... 30
金额 10 10 10 10 13 16 19 ... 31 ... 61 ... 91
```

显示拆位子电路也已验证：输入金额 1234 时，千位/百位/十位/个位分别输出 1/2/3/4。

## 已知限制

- **4 位显示上限**：里程和金额都只能显示 0000–9999；金额超过 9999 元时会溢出显示。
- **费率固定**：3 km、10 元、3 元/km、1 元/分钟均固化在电路中，修改费率需要改电路。
- **距离分辨率 50 m**：里程以 50 m 为单位累计，不能表示更细的距离。
- **纯仿真模型**：Logisim 是理想化逻辑仿真，不模拟门延迟、功耗和真实传感器抖动；`毛刺` 电路只是逻辑层面的消抖。
- **无数据保存/打印**：复位或关闭仿真后行程数据不保留。
